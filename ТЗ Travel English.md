# ТЗ: приложение Travel English

## 1. Что делаем

Мобильное веб-приложение (PWA) для iPhone, которое учит базовым английским словам и фразам, нужным в поездке за границу.

- Аудитория: русскоязычные туристы, уровень английского — нулевой или начальный.
- Первые пользователи: я и мои друзья. Продажа в App Store — не в этой версии.
- Язык интерфейса: русский.
- Я не программист. Объясняй свои действия простыми словами, без жаргона. Перед любым действием, которое удаляет файлы или его нельзя отменить, спрашивай меня.

## 2. Платформа и техника

- PWA: открывается по ссылке в Safari на iPhone, добавляется на экран «Домой» и выглядит как обычное приложение (иконка, полный экран, без адресной строки).
- Полностью работает без интернета после первого открытия (service worker кэширует все файлы, включая картинки и данные).
- Стек: обычные HTML, CSS и JavaScript, без фреймворков и без шага сборки. Причина: проще поддерживать и бесплатно размещать на GitHub Pages.
- Данные (слова, фразы, темы) хранятся в отдельном файле `data/words.json`, а не внутри кода. Добавление новых слов не должно требовать правки кода.
- Прогресс пользователя хранится в телефоне (localStorage). Сервера, аккаунтов и входа нет.
- Хостинг: GitHub Pages. Код хранится в репозитории на GitHub.
- Озвучка: встроенный синтезатор речи браузера (Web Speech API, `speechSynthesis`), голос en-US, без интернета. Если английский голос в телефоне не найден — показать понятную подсказку, а не ошибку.

## 3. Экраны

### 3.1 Главный экран — список блоков (тем)
- Карточка каждой темы: значок, название, сколько слов выучено из общего числа (например, «12 / 40»), полоса прогресса.
- Кнопка «Экзамен по всем блокам».

### 3.2 Экран темы
- Кнопка «Учить» — режим карточек.
- Кнопка «Экзамен по блоку».
- Список всех слов темы с отметкой «выучено / в процессе / новое».

### 3.3 Режим карточек
Лицевая сторона:
- картинка;
- английское слово или фраза крупно;
- кнопка озвучки (динамик).

После нажатия «Показать перевод»:
- перевод на русский;
- произношение русскими буквами (например, «чек-ин»);
- две кнопки: «Помню» и «Не помню».

Озвучка запускается только по нажатию кнопки (на iPhone звук без действия пользователя не работает).

### 3.4 Экзамен
Два варианта: по одному блоку и по всем блокам сразу.
- Показывается только английское слово (без картинки и без перевода) и кнопка озвучки.
- Пользователь вписывает перевод на русском в поле ввода и нажимает «Проверить».
- Сразу показать результат: верно или нет, и правильный перевод.
- В конце — итог: сколько верно из скольких, список ошибок.
- Слова с ошибками автоматически попадают на повторение в режиме карточек.
- Количество вопросов: по блоку — все слова блока; по всем блокам — 20 случайных слов (число легко поменять в настройках кода).

Правила проверки ответа:
- у слова может быть несколько верных переводов (`ticket` — «билет», «талон»); засчитывается любой из списка;
- не учитываются: регистр букв, пробелы по краям, знаки препинания, разница «ё» и «е»;
- для фраз принимается перевод без точного порядка мелких слов, если это легко сделать; если сложно — принимаются варианты из списка.

## 4. Как работает запоминание (интервальное повторение)

- «Не помню» — слово возвращается в этой же сессии через несколько карточек.
- «Помню» — интервал до следующего показа растёт по ступеням: 1 день, 3 дня, 7 дней, 14 дней, 30 дней.
- Слово считается выученным после ступени 7 дней.
- Ошибка на экзамене сбрасывает слово на первую ступень.

## 5. Формат данных `data/words.json`

Каждая запись:
- `id` — уникальный идентификатор;
- `topic` — идентификатор темы;
- `type` — `word` или `phrase`;
- `en` — английский текст;
- `ru` — список верных переводов, первый показывается на карточке;
- `pron_ru` — произношение русскими буквами;
- `image` — эмодзи или путь к картинке.

Пример:
```json
{
  "id": "airport-001",
  "topic": "airport",
  "type": "word",
  "en": "boarding pass",
  "ru": ["посадочный талон", "посадочный"],
  "pron_ru": "бординг пас",
  "image": "🎫"
}
```

Картинки: в первой версии — эмодзи (работают без интернета, ничего не весят, без проблем с авторскими правами). Позже можно заменить на SVG-иконки из бесплатного набора OpenMoji с соблюдением его лицензии.
